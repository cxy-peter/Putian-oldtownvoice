## 安全边界

实际 API Key/CSV 不提交 GitHub、不进源码包、不进前端。云端版只使用秘密环境变量。
云端词库/标注保存在浏览器，不在函数本地 SQLite 中。必须自行导出备份。实例内限额不跨冷启动/扩容累计，不应解释为计费硬上限。Cloudflare 换域名不是大陆可达保证。
